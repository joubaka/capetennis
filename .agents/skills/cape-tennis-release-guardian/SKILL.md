# Cape Tennis Release Guardian

Activate only for an explicitly requested release assessment or operation. Resolve the exact intended diff and HEAD, preserve unrelated changes, inspect deployment and migration allowlists, and verify required tests before acting.

Never infer permission for deployment, production migrations, publication, communication, payment changes, or live-data correction from approval to commit or push. Report the exact evidence reached and the safest remaining action.
